# Licensing

The application separates open-data scenes from restricted commercial imagery metadata.

| Source | License/usage | Redistribution |
| --- | --- | --- |
| Sentinel data via Copernicus Data Space and Earth Search | Open Copernicus Sentinel data; keep attribution to Copernicus/ESA/EU and catalog source | Metadata and public asset links may be displayed |
| Landsat Collection 2 via Earth Search/USGS | Public USGS/NASA Landsat data; cite USGS and source catalog | Metadata and public asset links may be displayed |
| NASA MODIS/VIIRS via CMR/LAADS | NASA Earth science data; cite NASA/LAADS/CMR | Metadata and open data links may be displayed |
| Copernicus EMSR927 source imagery from commercial/VHR missions | Restricted unless a specific product is explicitly open | Stored as `metadata-only`; imagery is not downloaded or rehosted |
| OpenStreetMap | ODbL with visible attribution | OSM attribution remains visible in the map |

Commercial sources such as WorldView, BlackSky, Legion, Satellogic, PeruSAT, Resurs-P and similar VHR products are not treated as open raster layers unless a separate open license is verified for that exact product.
